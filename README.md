# Mobile app skills

Agent skills for the jobs of running a mobile app: store optimization, review replies, Apple Search Ads, app metrics, launching and building.

Install one with `npx skills add fload-ai/mobile-app-skills --skill <name>`.

| Skill | What it does |
|---|---|
| [app-store-optimization](skills/app-store-optimization/SKILL.md) | Keywords, listings, screenshots and store tests |
| [app-review-replies](skills/app-review-replies/SKILL.md) | Read, triage and reply to reviews |
| [apple-search-ads](skills/apple-search-ads/SKILL.md) | Campaigns, bids, budgets and what's working |
| [mobile-app-metrics](skills/mobile-app-metrics/SKILL.md) | How an app is doing, what changed and why |
| [launch-an-app](skills/launch-an-app/SKILL.md) | Take an app to the App Store and Google Play |
| [build-an-app](skills/build-an-app/SKILL.md) | Go from an idea to a made app |
